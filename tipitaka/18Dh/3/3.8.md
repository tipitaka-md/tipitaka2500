# 3.8 Nandagopālakavatthu

* Cittavagga

* Nandagopālakavatthu

(42.)

45\. _Diso disaṁ yaṁ taṁ kayirā,_  
_verī vā pana verinaṁ;_  
_Micchāpaṇihitaṁ cittaṁ,_  
_pāpiyo naṁ tato kare._
