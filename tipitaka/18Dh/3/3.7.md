# 3.7 Pūtigattatissattheravatthu

* Cittavagga

* Pūtigattatissattheravatthu

(41.)

44\. _Aciraṁ vatayaṁ kāyo,_  
_pathaviṁ adhisessati;_  
_Chuddho apetaviññāṇo,_  
_niratthaṁva kaliṅgaraṁ._
