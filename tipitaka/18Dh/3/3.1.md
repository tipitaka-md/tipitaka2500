# 3.1 Meghiyattheravatthu

* Cittavagga

* Meghiyattheravatthu

(33.)

36\. _Phandanaṁ capalaṁ cittaṁ,_  
_dūrakkhaṁ dunnivārayaṁ;_  
_Ujuṁ karoti medhāvī,_  
_usukārova tejanaṁ._  

(34.)

37\. _Vārijova thale khitto,_  
_okamokataubbhato;_  
_Pariphandatidaṁ cittaṁ,_  
_māradheyyaṁ pahātave._
