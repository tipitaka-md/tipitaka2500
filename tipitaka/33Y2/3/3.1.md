# 3.1 Paccuppannavāra

* Pariññāvāra

* Paccuppannavāra

(206.)

963\. » Yo rūpakkhandhaṁ parijānāti so vedanākkhandhaṁ parijānātīti? Āmantā.

964\. « Yo vā pana vedanākkhandhaṁ parijānāti so rūpakkhandhaṁ parijānātīti? Āmantā.

965\. » Yo rūpakkhandhaṁ na parijānāti so vedanākkhandhaṁ na parijānātīti? Āmantā.

966\. « Yo vā pana vedanākkhandhaṁ na parijānāti so rūpakkhandhaṁ na parijānātīti? Āmantā.
