# 3.3 Anāgatavāra

* Pariññāvāra

* Anāgatavāra

(208.)

971\. » Yo rūpakkhandhaṁ parijānissati so vedanākkhandhaṁ parijānissatīti? Āmantā.

972\. « Yo vā pana vedanākkhandhaṁ parijānissati so rūpakkhandhaṁ parijānissatīti? Āmantā.

973\. » Yo rūpakkhandhaṁ na parijānissati so vedanākkhandhaṁ na parijānissatīti? Āmantā.

974\. « Yo vā pana vedanākkhandhaṁ na parijānissati so rūpakkhandhaṁ na parijānissatīti? Āmantā.
