# 3.3.7 Samattasutta

* Satipaṭṭhānasaṃyutta

* Sīlaṭṭhitivagga

* Samattasutta

(393.)

884\. Taṁyeva nidānaṁ. Ekamantaṁ nisinno kho āyasmā sāriputto āyasmantaṁ anuruddhaṁ etadavoca— “‘asekho, asekho’ti, āvuso anuruddha, vuccati. Kittāvatā nu kho, āvuso, asekho hotī”ti? “Catunnaṁ kho, āvuso, satipaṭṭhānānaṁ samattaṁ bhāvitattā asekho hoti.

885\. Katamesaṁ catunnaṁ? Idhāvuso, bhikkhu kāye kāyānupassī viharati ātāpī sampajāno satimā, vineyya loke abhijjhādomanassaṁ; vedanāsu…pe… citte…pe… dhammesu dhammānupassī viharati ātāpī sampajāno satimā, vineyya loke abhijjhādomanassaṁ. Imesaṁ kho, āvuso, catunnaṁ satipaṭṭhānānaṁ samattaṁ bhāvitattā asekho hotī”ti.

886\. Sattamaṁ.
