# 3.3.3 Nissaraṇiyasutta

* Tikanipāta

* Tatiyavagga

* Nissaraṇiyasutta

(72.)

465\. Vuttañhetaṁ bhagavatā vuttamarahatāti me sutaṁ—

466\. “Tisso imā, bhikkhave, nissaraṇiyā dhātuyo. Katamā tisso? Kāmānametaṁ nissaraṇaṁ yadidaṁ nekkhammaṁ, rūpānametaṁ nissaraṇaṁ yadidaṁ āruppaṁ, yaṁ kho pana kiñci bhūtaṁ saṅkhataṁ paṭiccasamuppannaṁ nirodho tassa nissaraṇaṁ— imā kho, bhikkhave, tisso nissaraṇiyā dhātuyo”ti. Etamatthaṁ bhagavā avoca. Tatthetaṁ iti vuccati—

467\. _“Kāmanissaraṇaṁ ñatvā,_  
_rūpānañca atikkamaṁ;_  
_Sabbasaṅkhārasamathaṁ,_  
_phusaṁ ātāpi sabbadā._  

468\. _Sa ve sammaddaso bhikkhu,_  
_yato tattha vimuccati;_  
_Abhiññāvosito santo,_  
_sa ve yogātigo munī”ti._  

469\. Ayampi attho vutto bhagavatā, iti me sutanti.

470\. Tatiyaṁ.
