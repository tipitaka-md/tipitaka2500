# 3.3.8 Bhidurasutta

* Tikanipāta

* Tatiyavagga

* Bhidurasutta

(77.)

510\. Vuttañhetaṁ bhagavatā vuttamarahatāti me sutaṁ—

511\. “Bhidurāyaṁ, bhikkhave, kāyo, viññāṇaṁ virāgadhammaṁ, sabbe upadhī aniccā dukkhā vipariṇāmadhammā”ti. Etamatthaṁ bhagavā avoca. Tatthetaṁ iti vuccati—

512\. _“Kāyañca bhiduraṁ ñatvā,_  
_Viññāṇañca virāgunaṁ;_  
_Upadhīsu bhayaṁ disvā,_  
_Jātimaraṇamaccagā;_  
_Sampatvā paramaṁ santiṁ,_  
_Kālaṁ kaṅkhati bhāvitatto”ti._  

513\. Ayampi attho vutto bhagavatā, iti me sutanti.

514\. Aṭṭhamaṁ.
