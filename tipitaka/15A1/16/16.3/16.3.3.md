# 16.3.3

* Ekadhammapāḷi

* Tatiyavagga

(310.)

399\. “Nāhaṁ, bhikkhave, aññaṁ ekadhammampi samanupassāmi yaṁ evaṁ mahāsāvajjaṁ yathayidaṁ, bhikkhave, micchādiṭṭhi. Micchādiṭṭhiparamāni, bhikkhave, mahāsāvajjānī”ti.
