# 3.3

* Akammaniyavagga

(23.)

49\. “Nāhaṁ, bhikkhave, aññaṁ ekadhammampi samanupassāmi yaṁ evaṁ abhāvitaṁ mahato anatthāya saṁvattati yathayidaṁ, bhikkhave, cittaṁ. Cittaṁ, bhikkhave, abhāvitaṁ mahato anatthāya saṁvattatī”ti.

50\. Tatiyaṁ.
