# 3.1

* Akammaniyavagga

(21.)

45\. “Nāhaṁ, bhikkhave, aññaṁ ekadhammampi samanupassāmi yaṁ evaṁ abhāvitaṁ akammaniyaṁ hoti yathayidaṁ, bhikkhave, cittaṁ. Cittaṁ, bhikkhave, abhāvitaṁ akammaniyaṁ hotī”ti.

46\. Paṭhamaṁ.
