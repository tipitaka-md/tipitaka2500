# 14.4.1--16

* Etadaggavagga

* Catutthavagga

(219.)

305\. “Etadaggaṁ, bhikkhave, mama sāvakānaṁ bhikkhūnaṁ bahussutānaṁ yadidaṁ ānando. (1)

(220.)

306\. … Satimantānaṁ yadidaṁ ānando. (2)

(221.)

307\. … Gatimantānaṁ yadidaṁ ānando. (3)

(222.)

308\. … Dhitimantānaṁ yadidaṁ ānando. (4)

(223.)

309\. … Upaṭṭhākānaṁ yadidaṁ ānando. (5)

(224.)

310\. … Mahāparisānaṁ yadidaṁ uruvelakassapo. (6)

(225.)

311\. … Kulappasādakānaṁ yadidaṁ kāḷudāyī. (7)

(226.)

312\. … Appābādhānaṁ yadidaṁ bākulo. (8)

(227.)

313\. … Pubbenivāsaṁ anussarantānaṁ yadidaṁ sobhito. (9)

(228.)

314\. … Vinayadharānaṁ yadidaṁ upāli. (10)

(229.)

315\. … Bhikkhunovādakānaṁ yadidaṁ nandako. (11)

(230.)

316\. … Indriyesu guttadvārānaṁ yadidaṁ nando. (12)

(231.)

317\. … Bhikkhuovādakānaṁ yadidaṁ mahākappino. (13)

(232.)

318\. … Tejodhātukusalānaṁ yadidaṁ sāgato. (14)

(233.)

319\. … Paṭibhāneyyakānaṁ yadidaṁ rādho. (15)

(234.)

320\. … Lūkhacīvaradharānaṁ yadidaṁ mogharājā”ti. (16)

321\. Vaggo catuttho.
