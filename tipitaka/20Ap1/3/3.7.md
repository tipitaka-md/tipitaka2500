# 3.7 Pulinapūjakattheraapadāna

* Subhūtivagga

* Pulinapūjakattheraapadāna

(165.)

1036\. _“Vipassissa bhagavato,_  
_bodhiyā pādaputtame;_  
_Purāṇapulinaṁ hitvā,_  
_suddhapulinamākiriṁ._  

(166.)

1037\. _Ekanavutito kappe,_  
_yaṁ pulinamadāsahaṁ;_  
_Duggatiṁ nābhijānāmi,_  
_pulinadānassidaṁ phalaṁ._  

(167.)

1038\. _Tiṁsatime ito kappe,_  
_rājā āsiṁ janādhibhū;_  
_Mahāpulinanāmena,_  
_cakkavattī mahabbalo._  

(168.)

1039\. _Paṭisambhidā catasso,_  
_vimokkhāpi ca aṭṭhime;_  
_Chaḷabhiññā sacchikatā,_  
_kataṁ buddhassa sāsanaṁ”._  

1040\. Itthaṁ sudaṁ āyasmā pulinapūjako thero imā gāthāyo abhāsitthāti.

1041\. Pulinapūjakattherassāpadānaṁ sattamaṁ.
