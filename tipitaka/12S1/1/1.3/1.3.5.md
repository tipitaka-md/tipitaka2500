# 1.3.5 Arahantasutta

* Devatāsaṃyutta

* Sattivagga

* Arahantasutta

(25.)

107\. _“Yo hoti bhikkhu arahaṁ katāvī,_  
_Khīṇāsavo antimadehadhārī;_  
_Ahaṁ vadāmītipi so vadeyya,_  
_Mamaṁ vadantītipi so vadeyyā”ti._  

108\. _“Yo hoti bhikkhu arahaṁ katāvī,_  
_Khīṇāsavo antimadehadhārī;_  
_Ahaṁ vadāmītipi so vadeyya,_  
_Mamaṁ vadantītipi so vadeyya;_  
_Loke samaññaṁ kusalo viditvā,_  
_Vohāramattena so vohareyyā”ti._  

109\. _“Yo hoti bhikkhu arahaṁ katāvī,_  
_Khīṇāsavo antimadehadhārī;_  
_Mānaṁ nu kho so upagamma bhikkhu,_  
_Ahaṁ vadāmītipi so vadeyya;_  
_Mamaṁ vadantītipi so vadeyyā”ti._  

110\. _“Pahīnamānassa na santi ganthā,_  
_Vidhūpitā mānaganthassa sabbe;_  
_Sa vītivatto maññataṁ sumedho,_  
_Ahaṁ vadāmītipi so vadeyya._  

111\. _Mamaṁ vadantītipi so vadeyya,_  
_Loke samaññaṁ kusalo viditvā;_  
_Vohāramattena so vohareyyā”ti._
