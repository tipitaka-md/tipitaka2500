# 3.3.7 Dasaṅgasutta

* Dhātusaṃyutta

* Kammapathavagga

* Dasaṅgasutta

(113.)

780\. Sāvatthiyaṁ viharati. “Dhātusova, bhikkhave, sattā saṁsandanti samenti. Micchādiṭṭhikā micchādiṭṭhikehi saddhiṁ saṁsandanti samenti; micchāsaṅkappā…pe… micchāvācā… micchākammantā… micchāājīvā… micchāvāyāmā… micchāsatino… micchāsamādhino micchāsamādhīhi saddhiṁ saṁsandanti samenti; micchāñāṇino micchāñāṇīhi saddhiṁ saṁsandanti samenti; micchāvimuttino micchāvimuttīhi saddhiṁ saṁsandanti samenti.

781\. Sammādiṭṭhikā sammādiṭṭhikehi saddhiṁ saṁsandanti samenti; sammāsaṅkappā…pe… sammāvācā… sammākammantā… sammāājīvā… sammāvāyāmā… sammāsatino… sammāsamādhino… sammāñāṇino sammāñāṇīhi saddhiṁ saṁsandanti samenti; sammāvimuttino sammāvimuttīhi saddhiṁ saṁsandanti samentī”ti.

782\. Sattamaṁ.

783\. (Sabbattha atītānāgatapaccuppannaṁ kātabbaṁ.)

784\. 

785\. _Asamāhitaṁ dussīlaṁ,_  
_pañca sikkhāpadāni ca;_  
_Satta kammapathā vuttā,_  
_dasakammapathena ca;_  
_Chaṭṭhaṁ aṭṭhaṅgiko vutto,_  
_dasaṅgena ca sattamaṁ._  

786\. Kammapathavaggo tatiyo.
