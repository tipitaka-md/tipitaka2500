# 3.4.6 Abhinandasutta

* Dhātusaṃyutta

* Catutthavagga

* Abhinandasutta

(119.)

809\. Sāvatthiyaṁ viharati. “Yo, bhikkhave, pathavīdhātuṁ abhinandati, dukkhaṁ so abhinandati. Yo dukkhaṁ abhinandati, aparimutto so dukkhasmāti vadāmi. Yo āpodhātuṁ abhinandati…pe… yo tejodhātuṁ… yo vāyodhātuṁ abhinandati, dukkhaṁ so abhinandati. Yo dukkhaṁ abhinandati, aparimutto so dukkhasmāti vadāmi.

810\. Yo ca kho, bhikkhave, pathavīdhātuṁ nābhinandati, dukkhaṁ so nābhinandati. Yo dukkhaṁ nābhinandati, parimutto so dukkhasmāti vadāmi. Yo āpodhātuṁ…pe… yo tejodhātuṁ… yo vāyodhātuṁ nābhinandati, dukkhaṁ so nābhinandati. Yo dukkhaṁ nābhinandati, parimutto so dukkhasmāti vadāmī”ti.

811\. Chaṭṭhaṁ.
