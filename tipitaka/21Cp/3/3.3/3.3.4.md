# 3.3.4 Maccharājacariya

* Yudhañjayavagga

* Saccapāramī

* Maccharājacariya

(83.)

360\. _“Punāparaṁ yadā homi,_  
_maccharājā mahāsare;_  
_Uṇhe sūriyasantāpe,_  
_sare udaka khīyatha._  

(84.)

361\. _Tato kākā ca gijjhā ca,_  
_kaṅkā kulalasenakā;_  
_Bhakkhayanti divārattiṁ,_  
_macche upanisīdiya._  

(85.)

362\. _Evaṁ cintesahaṁ tattha,_  
_saha ñātīhi pīḷito;_  
_‘Kena nu kho upāyena,_  
_ñātī dukkhā pamocaye’._  

(86.)

363\. _Vicintayitvā dhammatthaṁ,_  
_saccaṁ addasa passayaṁ;_  
_Sacce ṭhatvā pamocesiṁ,_  
_ñātīnaṁ taṁ atikkhayaṁ._  

(87.)

364\. _Anussaritvā sataṁ dhammaṁ,_  
_paramatthaṁ vicintayaṁ;_  
_Akāsiṁ saccakiriyaṁ,_  
_yaṁ loke dhuvasassataṁ._  

(88.)

365\. _‘Yato sarāmi attānaṁ,_  
_yato pattosmi viññutaṁ;_  
_Nābhijānāmi sañcicca,_  
_ekapāṇampi hiṁsitaṁ._  

(89.)

366\. _Etena saccavajjena,_  
_pajjunno abhivassatu;_  
_Abhitthanaya pajjunna,_  
_nidhiṁ kākassa nāsaya;_  
_Kākaṁ sokāya randhehi,_  
_macche sokā pamocaya’._  

(90.)

367\. _Saha kate saccavare,_  
_pajjunno abhigajjiya;_  
_Thalaṁ ninnañca pūrento,_  
_khaṇena abhivassatha._  

(91.)

368\. _Evarūpaṁ saccavaraṁ,_  
_katvā vīriyamuttamaṁ;_  
_Vassāpesiṁ mahāmeghaṁ,_  
_saccatejabalassito;_  
_Saccena me samo natthi,_  
_esā me saccapāramī”ti._  

369\. Maccharājacariyaṁ dasamaṁ.
