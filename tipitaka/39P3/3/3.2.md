# 3.2 Saṅkhataduka, Kusalattika

* Cūḷantaraduka, Kusalattika

* Saṅkhataduka, Kusalattika

(14.)

1497\. Saṅkhataṁ kusalaṁ dhammaṁ paṭicca saṅkhato kusalo dhammo uppajjati hetupaccayā. (Saṁkhittaṁ. Sappaccayasadisaṁ vitthāretabbaṁ.)

1498\. Saṅkhatadukakusalattikaṁ niṭṭhitaṁ.
