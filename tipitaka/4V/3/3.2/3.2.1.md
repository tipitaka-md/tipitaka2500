# 3.2.1 Agghasamodhānaparivāsa

* Samuccayakkhandhaka

* Parivāsa

* Agghasamodhānaparivāsa

(134.)

615\. Tena kho pana samayena aññataro bhikkhu sambahulā saṁghādisesā āpattiyo āpanno hoti— ekā āpatti ekāhappaṭicchannā, ekā āpatti dvīhappaṭicchannā, ekā āpatti tīhappaṭicchannā, ekā āpatti catūhappaṭicchannā, ekā āpatti pañcāhappaṭicchannā, ekā āpatti chāhappaṭicchannā, ekā āpatti sattāhappaṭicchannā, ekā āpatti aṭṭhāhappaṭicchannā, ekā āpatti navāhappaṭicchannā, ekā āpatti dasāhappaṭicchannā. So bhikkhūnaṁ ārocesi— “ahaṁ, āvuso, sambahulā saṁghādisesā āpattiyo āpajjiṁ— ekā āpatti ekāhappaṭicchannā…pe… ekā āpatti dasāhappaṭicchannā. Kathaṁ nu kho mayā paṭipajjitabban”ti? Bhagavato etamatthaṁ ārocesuṁ. “Tena hi, bhikkhave, saṁgho tassa bhikkhuno tāsaṁ āpattīnaṁ yā āpatti dasāhappaṭicchannā tassā agghena samodhānaparivāsaṁ detu. Evañca pana, bhikkhave, dātabbo—

616\. Tena, bhikkhave, bhikkhunā saṁghaṁ upasaṅkamitvā…pe… evamassa vacanīyo— ‘ahaṁ, bhante, sambahulā saṁghādisesā āpattiyo āpajjiṁ— ekā āpatti ekāhappaṭicchannā…pe… ekā āpatti dasāhappaṭicchannā. Sohaṁ, bhante, saṁghaṁ tāsaṁ āpattīnaṁ yā āpatti dasāhappaṭicchannā tassā agghena samodhānaparivāsaṁ yācāmī’ti. Dutiyampi yācitabbo. Tatiyampi yācitabbo. Byattena bhikkhunā paṭibalena saṁgho ñāpetabbo—

(135.)

617\. ‘Suṇātu me, bhante, saṁgho. Ayaṁ itthannāmo bhikkhu sambahulā saṁghādisesā āpattiyo āpajji— ekā āpatti ekāhappaṭicchannā…pe… ekā āpatti dasāhappaṭicchannā. So saṁghaṁ tāsaṁ āpattīnaṁ yā āpatti dasāhappaṭicchannā tassā agghena samodhānaparivāsaṁ yācati. Yadi saṁghassa pattakallaṁ, saṁgho itthannāmassa bhikkhuno tāsaṁ āpattīnaṁ yā āpatti dasāhappaṭicchannā tassā agghena samodhānaparivāsaṁ dadeyya. Esā ñatti.

618\. Suṇātu me, bhante, saṁgho. Ayaṁ itthannāmo bhikkhu sambahulā saṁghādisesā āpattiyo āpajji— ekā āpatti ekāhappaṭicchannā…pe… ekā āpatti dasāhappaṭicchannā. So saṁghaṁ tāsaṁ āpattīnaṁ yā āpatti dasāhappaṭicchannā tassā agghena samodhānaparivāsaṁ yācati. Saṁgho itthannāmassa bhikkhuno tāsaṁ āpattīnaṁ yā āpatti dasāhappaṭicchannā tassā agghena samodhānaparivāsaṁ deti. Yassāyasmato khamati itthannāmassa bhikkhuno tāsaṁ āpattīnaṁ yā āpatti dasāhappaṭicchannā; tassā agghena samodhānaparivāsassa dānaṁ, so tuṇhassa; yassa nakkhamati, so bhāseyya.

619\. Dutiyampi etamatthaṁ vadāmi…pe… tatiyampi etamatthaṁ vadāmi…pe… .

620\. Dinno saṁghena itthannāmassa bhikkhuno tāsaṁ āpattīnaṁ yā āpatti dasāhappaṭicchannā tassā agghena samodhānaparivāso. Khamati saṁghassa, tasmā tuṇhī, evametaṁ dhārayāmī’”ti.
