# 2.3.3.29 Muṭṭhasaccaduka

* Niddesa

* Nikkhepakaṇḍa

* Suttantikadukanikkhepa

* Muṭṭhasaccaduka

(1356.)

2061\. Tattha katamaṁ muṭṭhasaccaṁ? Yā asati ananussati appaṭissati asati asaraṇatā adhāraṇatā pilāpanatā sammussanatā— idaṁ vuccati muṭṭhasaccaṁ.

(1357.)

2062\. Tattha katamaṁ asampajaññaṁ? Yaṁ aññāṇaṁ adassanaṁ…pe… avijjālaṅgī moho akusalamūlaṁ— idaṁ vuccati asampajaññaṁ.
