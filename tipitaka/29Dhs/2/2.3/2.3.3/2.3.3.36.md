# 2.3.3.36 Sīlasampadāduka

* Niddesa

* Nikkhepakaṇḍa

* Suttantikadukanikkhepa

* Sīlasampadāduka

(1370.)

2075\. Tattha katamā sīlasampadā? Yo kāyiko avītikkamo, vācasiko avītikkamo, kāyikavācasiko avītikkamo— ayaṁ vuccati sīlasampadā. Sabbopi sīlasaṁvaro sīlasampadā.

(1371.)

2076\. Tattha katamā diṭṭhisampadā? Atthi dinnaṁ, atthi yiṭṭhaṁ, atthi hutaṁ, atthi sukatadukkaṭānaṁ kammānaṁ phalaṁ vipāko, atthi ayaṁ loko, atthi paro loko, atthi mātā, atthi pitā, atthi sattā opapātikā, atthi loke samaṇabrāhmaṇā sammaggatā sammāpaṭipannā ye imañca lokaṁ parañca lokaṁ sayaṁ abhiññā sacchikatvā pavedentīti; yā evarūpā paññā pajānanā…pe… amoho dhammavicayo sammādiṭṭhi— ayaṁ vuccati diṭṭhisampadā. Sabbāpi sammādiṭṭhi diṭṭhisampadā.
