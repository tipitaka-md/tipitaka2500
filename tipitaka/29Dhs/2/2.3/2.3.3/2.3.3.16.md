# 2.3.3.16 Hiriduka

* Niddesa

* Nikkhepakaṇḍa

* Suttantikadukanikkhepa

* Hiriduka

(1330.)

2035\. Tattha katamā hirī? Yaṁ hirīyati hiriyitabbena, hirīyati pāpakānaṁ akusalānaṁ dhammānaṁ samāpattiyā— ayaṁ vuccati hirī.

(1331.)

2036\. Tattha katamaṁ ottappaṁ? Yaṁ ottappati ottappitabbena, ottappati pāpakānaṁ akusalānaṁ dhammānaṁ samāpattiyā— idaṁ vuccati ottappaṁ.
