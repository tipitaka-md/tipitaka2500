# 2.3.3.8 Paññattiduka

* Niddesa

* Nikkhepakaṇḍa

* Suttantikadukanikkhepa

* Paññattiduka

(1315.)

2019\. Katame dhammā paññatti? Yā tesaṁ tesaṁ dhammānaṁ saṅkhā samaññā paññatti vohāro nāmaṁ nāmakammaṁ nāmadheyyaṁ nirutti byañjanaṁ abhilāpo— ime dhammā paññatti.

2020\. Sabbeva dhammā paññattipathā.
