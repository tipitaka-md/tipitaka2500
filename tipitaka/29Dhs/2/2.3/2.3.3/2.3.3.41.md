# 2.3.3.41 Vijjāduka

* Niddesa

* Nikkhepakaṇḍa

* Suttantikadukanikkhepa

* Vijjāduka

(1380.)

2085\. Vijjāti— tisso vijjā— pubbenivāsānussati ñāṇaṁ vijjā, sattānaṁ cutūpapāte ñāṇaṁ vijjā, āsavānaṁ khaye ñāṇaṁ vijjā.

(1381.)

2086\. Vimuttīti— dve vimuttiyo— cittassa adhimutti, nibbānañca.
