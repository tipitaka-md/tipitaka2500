# 2.4.1 Anulomapuggala

* Mahāvāra

* Pariññāvāra

* Anulomapuggala

(198.)

1359\. » Yo kāmarāgānusayaṁ parijānāti so paṭighānusayaṁ parijānātīti? Āmantā.

1360\. « Yo vā pana paṭighānusayaṁ parijānāti so kāmarāgānusayaṁ parijānātīti? Āmantā.

1361\. » Yo kāmarāgānusayaṁ parijānāti so mānānusayaṁ parijānātīti?

1362\. Tadekaṭṭhaṁ parijānāti.

1363\. « Yo vā pana mānānusayaṁ parijānāti so kāmarāgānusayaṁ parijānātīti? No.

1364\. » Yo kāmarāgānusayaṁ parijānāti so diṭṭhānusayaṁ…pe… vicikicchānusayaṁ parijānātīti? No.

1365\. « Yo vā pana vicikicchānusayaṁ parijānāti so kāmarāgānusayaṁ parijānātīti?

1366\. Tadekaṭṭhaṁ parijānāti.

1367\. » Yo kāmarāgānusayaṁ parijānāti so bhavarāgānusayaṁ…pe… avijjānusayaṁ parijānātīti?

1368\. Tadekaṭṭhaṁ parijānāti.

1369\. « Yo vā pana avijjānusayaṁ parijānāti so kāmarāgānusayaṁ parijānātīti? No.

(199.)

1370\. » Yo paṭighānusayaṁ parijānāti so mānānusayaṁ parijānātīti?

1371\. Tadekaṭṭhaṁ parijānāti.

1372\. « Yo vā pana mānānusayaṁ parijānāti so paṭighānusayaṁ parijānātīti? No.

1373\. » Yo paṭighānusayaṁ parijānāti so diṭṭhānusayaṁ…pe… vicikicchānusayaṁ parijānātīti? No.

1374\. « Yo vā pana vicikicchānusayaṁ parijānāti so paṭighānusayaṁ parijānātīti?

1375\. Tadekaṭṭhaṁ parijānāti.

1376\. » Yo paṭighānusayaṁ parijānāti so bhavarāgānusayaṁ…pe… avijjānusayaṁ parijānātīti?

1377\. Tadekaṭṭhaṁ parijānāti.

1378\. « Yo vā pana avijjānusayaṁ parijānāti so paṭighānusayaṁ parijānātīti? No.

(200.)

1379\. » Yo mānānusayaṁ parijānāti so diṭṭhānusayaṁ…pe… vicikicchānusayaṁ parijānātīti? No.

1380\. « Yo vā pana vicikicchānusayaṁ parijānāti so mānānusayaṁ parijānātīti?

1381\. Tadekaṭṭhaṁ parijānāti.

1382\. » Yo mānānusayaṁ parijānāti so bhavarāgānusayaṁ…pe… avijjānusayaṁ parijānātīti? Āmantā.

1383\. « Yo vā pana avijjānusayaṁ parijānāti so mānānusayaṁ parijānātīti? Āmantā.

(201.)

1384\. » Yo diṭṭhānusayaṁ parijānāti so vicikicchānusayaṁ parijānātīti? Āmantā.

1385\. « Yo vā pana vicikicchānusayaṁ parijānāti so diṭṭhānusayaṁ parijānātīti? Āmantā…pe… .

(202.)

1386\. » Yo vicikicchānusayaṁ parijānāti so bhavarāgānusayaṁ…pe… avijjānusayaṁ parijānātīti?

1387\. Tadekaṭṭhaṁ parijānāti.

1388\. « Yo vā pana avijjānusayaṁ parijānāti so vicikicchānusayaṁ parijānātīti? No.

(203.)

1389\. » Yo bhavarāgānusayaṁ parijānāti so avijjānusayaṁ parijānātīti? Āmantā.

1390\. « Yo vā pana avijjānusayaṁ parijānāti so bhavarāgānusayaṁ parijānātīti? Āmantā. (Ekamūlakaṁ.)

(204.)

1391\. » Yo kāmarāgānusayañca paṭighānusayañca parijānāti so mānānusayaṁ parijānātīti?

1392\. Tadekaṭṭhaṁ parijānāti.

1393\. « Yo vā pana mānānusayaṁ parijānāti so kāmarāgānusayañca paṭighānusayañca parijānātīti? No.

1394\. » Yo kāmarāgānusayañca paṭighānusayañca parijānāti so diṭṭhānusayaṁ…pe… vicikicchānusayaṁ parijānātīti? No.

1395\. « Yo vā pana vicikicchānusayaṁ parijānāti so kāmarāgānusayañca paṭighānusayañca parijānātīti?

1396\. Tadekaṭṭhaṁ parijānāti.

1397\. » Yo kāmarāgānusayañca paṭighānusayañca parijānāti so bhavarāgānusayaṁ…pe… avijjānusayaṁ parijānātīti?

1398\. Tadekaṭṭhaṁ parijānāti.

1399\. « Yo vā pana avijjānusayaṁ parijānāti so kāmarāgānusayañca paṭighānusayañca parijānātīti? No. (Dukamūlakaṁ.)

(205.)

1400\. » Yo kāmarāgānusayañca paṭighānusayañca mānānusayañca parijānāti so diṭṭhānusayaṁ…pe… vicikicchānusayaṁ parijānātīti? Natthi.

1401\. « Yo vā pana vicikicchānusayaṁ parijānāti so kāmarāgānusayañca paṭighānusayañca mānānusayañca parijānātīti?

1402\. Tadekaṭṭhaṁ parijānāti.

1403\. » Yo kāmarāgānusayañca paṭighānusayañca mānānusayañca parijānāti so bhavarāgānusayaṁ…pe… avijjānusayaṁ parijānātīti? Natthi.

1404\. « Yo vā pana avijjānusayaṁ parijānāti so kāmarāgānusayañca paṭighānusayañca mānānusayañca parijānātīti?

1405\. Mānānusayaṁ parijānāti. (Tikamūlakaṁ.)

(206.)

1406\. » Yo kāmarāgānusayañca paṭighānusayañca mānānusayañca diṭṭhānusayañca parijānāti so vicikicchānusayaṁ parijānātīti? Natthi.

1407\. « Yo vā pana vicikicchānusayaṁ parijānāti so kāmarāgānusayañca paṭighānusayañca mānānusayañca diṭṭhānusayañca parijānātīti?

1408\. Diṭṭhānusayaṁ parijānāti kāmarāgānusayañca paṭighānusayañca mānānusayañca tadekaṭṭhaṁ parijānāti…pe… . (Catukkamūlakaṁ.)

(207.)

1409\. » Yo kāmarāgānusayañca paṭighānusayañca mānānusayañca diṭṭhānusayañca vicikicchānusayañca parijānāti so bhavarāgānusayaṁ…pe… avijjānusayaṁ parijānātīti? Natthi.

1410\. « Yo vā pana avijjānusayaṁ parijānāti so kāmarāgānusayañca paṭighānusayañca mānānusayañca diṭṭhānusayañca vicikicchānusayañca parijānātīti?

1411\. Mānānusayaṁ parijānāti. (Pañcakamūlakaṁ.)

(208.)

1412\. » Yo kāmarāgānusayañca paṭighānusayañca mānānusayañca diṭṭhānusayañca vicikicchānusayañca bhavarāgānusayañca parijānāti so avijjānusayaṁ parijānātīti? Natthi.

1413\. « Yo vā pana avijjānusayaṁ parijānāti so kāmarāgānusayañca paṭighānusayañca mānānusayañca diṭṭhānusayañca vicikicchānusayañca bhavarāgānusayañca parijānātīti?

1414\. Mānānusayañca bhavarāgānusayañca parijānāti. (Chakkamūlakaṁ.)
