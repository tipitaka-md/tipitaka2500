# 3.3 Anāgatavāra

* Pariññāvāra

* Anāgatavāra

(251.)

1918\. » Yo cakkhāyatanaṁ parijānissati so sotāyatanaṁ parijānissatīti? Āmantā.

1919\. « Yo vā pana sotāyatanaṁ parijānissati so cakkhāyatanaṁ parijānissatīti? Āmantā.

1920\. » Yo cakkhāyatanaṁ na parijānissati so sotāyatanaṁ na parijānissatīti? Āmantā.

1921\. « Yo vā pana sotāyatanaṁ na parijānissati so cakkhāyatanaṁ na parijānissatīti? Āmantā.
