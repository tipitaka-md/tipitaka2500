# 3.1 Paccuppannavāra

* Pariññāvāra

* Paccuppannavāra

(249.)

1910\. » Yo cakkhāyatanaṁ parijānāti so sotāyatanaṁ parijānātīti? Āmantā.

1911\. « Yo vā pana sotāyatanaṁ parijānāti so cakkhāyatanaṁ parijānātīti? Āmantā.

1912\. » Yo cakkhāyatanaṁ na parijānāti so sotāyatanaṁ na parijānātīti? Āmantā.

1913\. « Yo vā pana sotāyatanaṁ na parijānāti so cakkhāyatanaṁ na parijānātīti? Āmantā.
