# 3.2 Atītavāra

* Pariññāvāra

* Atītavāra

(250.)

1914\. » Yo cakkhāyatanaṁ parijānittha so sotāyatanaṁ parijānitthāti? Āmantā.

1915\. « Yo vā pana sotāyatanaṁ parijānittha so cakkhāyatanaṁ parijānitthāti? Āmantā.

1916\. » Yo cakkhāyatanaṁ na parijānittha so sotāyatanaṁ na parijānitthāti? Āmantā.

1917\. « Yo vā pana sotāyatanaṁ na parijānittha so cakkhāyatanaṁ na parijānitthāti? Āmantā.
