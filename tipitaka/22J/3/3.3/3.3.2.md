# 3.3.2 Byagghajātaka

* Tikanipāta

* Udapānavagga

* Byagghajātaka

(64.)

758\. _“Yena mittena saṁsaggā,_  
_yogakkhemo vihiyyati;_  
_Pubbevajjhābhavaṁ tassa,_  
_rukkhe akkhīva paṇḍito._  

(65.)

759\. _Yena mittena saṁsaggā,_  
_yogakkhemo pavaḍḍhati;_  
_Kareyyattasamaṁ vuttiṁ,_  
_sabbakiccesu paṇḍito”._  

(66.)

760\. _“Etha byagghā nivattavho,_  
_Paccupetha mahāvanaṁ;_  
_Mā vanaṁ chindi nibyagghaṁ,_  
_Byagghā māhesu nibbanā”ti._  

761\. Byagghajātakaṁ dutiyaṁ.
