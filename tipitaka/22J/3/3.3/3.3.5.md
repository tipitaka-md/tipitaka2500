# 3.3.5 Rucirajātaka

* Tikanipāta

* Udapānavagga

* Rucirajātaka

(73.)

770\. _“Kāyaṁ balākā rucirā,_  
_kākanīḷasmimacchati;_  
_Caṇḍo kāko sakhā mayhaṁ,_  
_yassa cetaṁ kulāvakaṁ”._  

(74.)

771\. _“Nanu maṁ samma jānāsi,_  
_dija sāmākabhojana;_  
_Akatvā vacanaṁ tuyhaṁ,_  
_passa lūnosmi āgato”._  

(75.)

772\. _“Punapāpajjasī samma,_  
_sīlañhi tava tādisaṁ;_  
_Na hi mānusakā bhogā,_  
_subhuñjā honti pakkhinā”ti._  

773\. Rucirajātakaṁ pañcamaṁ.
