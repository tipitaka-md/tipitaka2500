# 3.3.6 Garudhammajātaka

* Tikanipāta

* Udapānavagga

* Garudhammajātaka

(76.)

774\. _“Tava saddhañca sīlañca,_  
_viditvāna janādhipa;_  
_Vaṇṇaṁ añjanavaṇṇena,_  
_kāliṅgasmiṁ nimimhase”._  

(77.)

775\. _“Annabhaccā cabhaccā ca,_  
_yodha uddissa gacchati;_  
_Sabbe te appaṭikkhippā,_  
_pubbācariyavaco idaṁ._  

(78.)

776\. _Dadāmi vo brāhmaṇā nāgametaṁ,_  
_Rājārahaṁ rājabhoggaṁ yasassinaṁ;_  
_Alaṅkataṁ hemajālābhichannaṁ,_  
_Sasārathiṁ gacchatha yena kāman”ti._  

777\. Garudhammajātakaṁ chaṭṭhaṁ.
