# 3.3.9 Satapattajātaka

* Tikanipāta

* Udapānavagga

* Satapattajātaka

(85.)

786\. _“Yathā māṇavako panthe,_  
_siṅgāliṁ vanagocariṁ;_  
_Atthakāmaṁ pavedentiṁ,_  
_anatthakāmāti maññati;_  
_Anatthakāmaṁ satapattaṁ,_  
_atthakāmoti maññati._  

(86.)

787\. _Evameva idhekacco,_  
_puggalo hoti tādiso;_  
_Hitehi vacanaṁ vutto,_  
_paṭigaṇhāti vāmato._  

(87.)

788\. _Ye ca kho naṁ pasaṁsanti,_  
_bhayā ukkaṁsayanti vā;_  
_Tañhi so maññate mittaṁ,_  
_satapattaṁva māṇavo”ti._  

789\. Satapattajātakaṁ navamaṁ.
