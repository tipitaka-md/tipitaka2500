# 3.3.3 Kacchapajātaka

* Tikanipāta

* Udapānavagga

* Kacchapajātaka

(67.)

762\. _“Ko nu uddhitabhattova,_  
_pūrahatthova brāhmaṇo;_  
_Kahaṁ nu bhikkhaṁ acari,_  
_kaṁ saddhaṁ upasaṅkami”._  

(68.)

763\. _“Ahaṁ kapismi dummedho,_  
_anāmāsāni āmasiṁ;_  
_Tvaṁ maṁ mocaya bhaddaṁ te,_  
_mutto gaccheyya pabbataṁ”._  

(69.)

764\. _“Kacchapā kassapā honti,_  
_Koṇḍaññā honti makkaṭā;_  
_Muñca kassapa koṇḍaññaṁ,_  
_Kataṁ methunakaṁ tayā”ti._  

765\. Kacchapajātakaṁ tatiyaṁ.
