# 3.2.3 Cūḷapalobhanajātaka

* Tikanipāta

* Padumavagga

* Cūḷapalobhanajātaka

(37.)

720\. _“Abhijjamāne vārismiṁ,_  
_sayaṁ āgamma iddhiyā;_  
_Missībhāvitthiyā gantvā,_  
_saṁsīdasi mahaṇṇave._  

(38.)

721\. _Āvaṭṭanī mahāmāyā,_  
_brahmacariyavikopanā;_  
_Sīdanti naṁ viditvāna,_  
_ārakā parivajjaye._  

(39.)

722\. _Yaṁ etā upasevanti,_  
_chandasā vā dhanena vā;_  
_Jātavedova saṁ ṭhānaṁ,_  
_khippaṁ anudahanti nan”ti._  

723\. Cūḷapalobhanajātakaṁ tatiyaṁ.
