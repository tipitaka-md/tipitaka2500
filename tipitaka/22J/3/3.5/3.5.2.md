# 3.5.2 Supattajātaka

* Tikanipāta

* Kumbhavagga

* Supattajātaka

(124.)

842\. _“Bārāṇasyaṁ mahārāja,_  
_kākarājā nivāsako;_  
_Asītiyā sahassehi,_  
_supatto parivārito._  

(125.)

843\. _Tassa dohaḷinī bhariyā,_  
_Suphassā bhakkhitumicchati;_  
_Rañño mahānase pakkaṁ,_  
_Paccagghaṁ rājabhojanaṁ._  

(126.)

844\. _Tesāhaṁ pahito dūto,_  
_rañño camhi idhāgato;_  
_Bhattu apacitiṁ kummi,_  
_nāsāyamakaraṁ vaṇan”ti._  

845\. Supattajātakaṁ dutiyaṁ.
