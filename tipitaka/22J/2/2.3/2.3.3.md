# 2.3.3 Makkaṭajātaka

* Dukanipāta

* Kalyāṇavagga

* Makkaṭajātaka

(45.)

412\. _“Tāta māṇavako eso,_  
_tālamūlaṁ apassito;_  
_Agārakañcidaṁ atthi,_  
_handa demassagārakaṁ”._  

(46.)

413\. _“Mā kho tvaṁ tāta pakkosi,_  
_dūseyya no agārakaṁ;_  
_Netādisaṁ mukhaṁ hoti,_  
_brāhmaṇassa susīlino”ti._  

414\. Makkaṭajātakaṁ tatiyaṁ.
