# 81 Sanidassanattika, Bhāvanāyapahātabbahetukaduka

* Sanidassanattika, Bhāvanāyapahātabbahetukaduka

(131.)

316\. Anidassanaappaṭighaṁ bhāvanāya pahātabbahetukaṁ dhammaṁ paṭicca naanidassanaappaṭigho nabhāvanāya pahātabbahetuko dhammo uppajjati hetupaccayā. (Saṁkhittaṁ.) Hetuyā cha, ārammaṇe tīṇi…pe… avigate cha.

317\. Anidassanaappaṭighaṁ nabhāvanāya pahātabbahetukaṁ dhammaṁ paṭicca nasanidassanasappaṭigho nanabhāvanāya pahātabbahetuko dhammo uppajjati hetupaccayā. (Saṁkhittaṁ.) Hetuyā tīṇi…pe… avigate tīṇi.
